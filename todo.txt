In order to dual boot windows:

# Use sudo os-prober and make sure the windows boot
sudo os-prober
# Add GRUB_DISABLE_OS_PROBER=false to grub config
sudo vim /etc/default/grub
# Update grub config
sudo grub-mkconfig -o /boot/grub/grub.cfg
